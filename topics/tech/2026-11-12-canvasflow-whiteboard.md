## Summary
CanvasFlow: an infinite-canvas desktop whiteboard for thinking, not presenting. Boards are plain local files, no account. Its signature is an always-on-bottom window mode, so the board sits behind your windows like a desk mat. Shapes, sticky notes, code blocks, embeds, connectors and freehand strokes. Windows first.
