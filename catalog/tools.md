MetaHuman Maker by TREE Industries ([github.com/TREE-Ind/MetahumanMaker](https://github.com/TREE-Ind/MetahumanMaker)) is an open-source (MIT) Blender add-on that turns photos or source meshes into editable MetaHuman characters for Unreal Engine: wrap and fit the head and body, sculpt and repair regions, rebuild missing skin detail with up to 8K textures, then send rigs and grooms into Unreal. ### [Cloudflare Computer](../topics/ai/cloudflare-computer-agent-sandbox.md)

`tool` · ai · <https://github.com/cloudflare/computer>

- **Why saved:** Cloudflare computer
- **Tags:** #agents #open-source #sandbox #to-try

Cloudflare open-sourced Cloudflare Computer (`@cloudflare/computer`, MIT), a persistent "computer" for AI agents: a virtual filesystem that lives inside a Durable Object with its state in SQLite, so an agent's files survive after a session ends. One `workspace.runtime.exec()` call runs code on a pluggable backend: a full Linux sandbox container (FUSE-mounted via `computerd`), a just-bash shell in a Dynamic Worker, or "codemode" JavaScript modules with git and artifact helpers. Found via an Instagram reel by @angelotrifanoff.ai.

### [Unslop UI skill](../topics/design/unslop-ui-skill.md)

`tool` · design · <https://github.com/heydamir/unslop>

- **Why saved:** the skill repo from the AI slop vs senior designer reel, turns AI-looking UI into a designed interface
- **Tags:** #claude #ui #visual-design #open-source #to-try

unslop by Damir Sokolovsky (@heydamir) is an open-source skill for Claude Code and Codex that turns vibecoded, AI-looking UI into a designed interface. It first audits the screen for slop signs (purple gradients, glows, emoji labels, loud copy, uneven spacing), proposes a visual direction that fits the product, then revises in a fixed order: spacing, colour, icons, copy, type, layout, details, visuals, motion. It can also generate hero images through fal, Replicate, OpenAI or Higgsfield, asking before each paid generation, and render a short before/after video with Playwright and ffmpeg. It works with React, Next.js, Vue, Svelte, Tailwind or plain HTML/CSS, or from a live URL. Install it into `~/.claude/skills/` and run `/unslop`. License is CC BY 4.0; about 6.5k stars.

### [Toyxyz retarget add-on](../topics/animation/toyxyz-blender-retargeter.md)

`tool` · animation · <https://x.com/toyxyz3/status/2120734403605500312>

- **Why saved:** cool plugin, and also cool way to retarget motion between characters with different body proportions; also a very cool art style for showing prototype models in a game
- **Style:** blocky segmented mannequins, one flat pastel colour per character, dark grey blender viewport grid
- **Kit:** motion, 3d
- **Tags:** #blender #motion-capture #rigging #game-inspiration

A free Blender add-on by @toyxyz3 that retargets mocap between characters with very different body proportions (tall, short, stocky). It copies joint rotations with FK, then adjusts the root motion for each rig's limb lengths, so feet don't slide and you avoid the IK popping of IK-based retargeting. Code: https://github.com/toyxyz/toyxyz-blender-retargeter
