**First step today:** Draw the taxi's side view at 32px wide, slice it into rows, and write a vanilla JS canvas loop that draws the slices 1 px apart rotated by the car's angle, steered with arrow keys on a flat teal tile.

## 2. Glyph-grid context theme

**Build:** A Claude Code desktop theme mod where the background is a live glyph-grid network (tiny dots, squares and crosses on charcoal in orange, purple, green and cream). As the context fills, the grid grows new branches and gets denser; running `/compact` collapses it into a single-blue swirl that resolves back into a small seed grid. A small serif label in the corner shows "Neural Vectoring · 44% context".
**From:** [Claude Code reactive theme](../topics/ai/claude-code-reactive-theme.md) + [Neural network data viz](../topics/design/neural-network-data-viz.md)
**Why it fits:** He called the reactive theme an "insane use case for custom theme or mods", and this uses the glyph-grid data viz look he just saved instead of a seasonal scene, in the dark, one-glow style of his own tools.
**First step today:** Install the theme-examples plugin, copy the snowfall mod's `turn.step` hook, and swap its scene for a canvas that draws an N-by-N glyph grid where the number of lit cells follows the context percentage.
**Status:** suggested
