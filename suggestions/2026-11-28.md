## 1. Labs ability shaders

**Build:** A small "abilities" wall on the Revolio Labs site: six live GLSL effects (a vortex ring, a shield pop, a ground slam...) running at 60 fps in three.js, each rebuilt from a 12-frame GIF by the AnyVFX skill. Hover one to play it, click to drop it onto your own image as a first, tiny version of the Ladybug-style VFX feature. Every effect is one fragment shader with no textures, so the page stays light.
**From:** [AnyVFX shader skill](../topics/gamedev/anyvfx-shader-skill.md) + [Revolio VFX feature](../topics/revolio/revolio-labs-vfx-feature.md) + [Revolio Labs site](../topics/revolio/revolio-labs-site.md)
**Why it fits:** It finally moves your oldest open to-do (the VFX feature), it's agent-driven, and the shaders double as hit effects for your three.js games.
**First step today:** Clone the AnyVFX repo, run its skill in Claude Code on one of its example GIFs, and paste the shader it writes into a bare three.js `ShaderMaterial` plane. If that one looks right, generate two more GIFs of your own and repeat.
**Status:** suggested

## 2. Dot-glyph Claude toasts

**Build:** A PXLVZN menu-bar app (SwiftUI) that turns Claude Code events into the "agentic toasts" look: session finished shows a +/− lines grid, tests passed a green dot grid, context almost full an amber grid filling up with a Compact button. The menu-bar icon itself is a tiny dot grid of your session and weekly usage, so you stop checking `/usage` by hand.
**From:** [Agentic toasts UI](../topics/design/agentic-toasts-ui.md) + [Claude Code usage snapshot](../topics/tech/claude-code-usage-snapshot.md) + [PXL app hub](../topics/tech/pxl-app-hub.md)
**Why it fits:** You live in Claude Code, you already wanted to track usage, and it's the dot-matrix utility UI you keep saving, in your dark-with-one-accent look.
**First step today:** Add a Claude Code `Stop` hook that writes `{event, lines_added, lines_removed, time}` to a JSON file, then make a 40-line SwiftUI `MenuBarExtra` that reads it and draws the last event as a 6x6 dot grid.
**Status:** suggested

## 3. BulkBros move minis

**Build:** Give every exercise in BulkBros a tiny rotatable 3D figure: blocky segmented mannequins in one flat pastel colour (the Toyxyz prototype look), animated from a few KB of joint keyframes per move and drawn live with three.js, instead of GIFs or videos. The PPL split list gets a moving mini figure as each row's icon.
**From:** [Tiny 3D exercise animations](../topics/tech/tiny-3d-exercise-animations.md) + [BulkBros gym app](../topics/health/bulkbros-gym-app.md) + [Toyxyz retarget add-on](../topics/animation/toyxyz-blender-retargeter.md)
**Why it fits:** It's a real upgrade to an app you use every day, it's a weekend of three.js, and the blocky mannequin is a look you saved for exactly this.
**First step today:** Build one mannequin from 10 boxes in three.js and hand-key a squat as 4 poses in a small JSON (hip, knee, shoulder angles), then tween between them. Check the file size; if it's under 3 KB, do bench press next.
**Status:** suggested
